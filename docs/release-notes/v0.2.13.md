# Pelmet 0.2.13

Fixed:

- ⌘-dragging a system item such as Sound, battery or Wi-Fi across the
  chevron in the menu bar did not stick: the icon hid again on the next
  rehide and the layout editor kept it in its old section. Those items now
  adopt their new section like any other icon. Siri and the other items
  macOS pins in place are still left alone.
