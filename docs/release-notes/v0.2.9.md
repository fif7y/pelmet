# Pelmet 0.2.9

Fixed:

- Dragging in the layout editor is steady now. Each section is one drop
  target with a single placeholder that follows the pointer, so tiles no
  longer twitch as you cross them, and the drop lands where the
  placeholder was. Releasing outside a section puts the tile back.
- The overflow chevron is found on non-English systems. Pelmet matched it
  by its English accessibility label, so on any other system language the
  boundary walk and editor placement quietly did nothing. It now reads
  every translation from macOS itself.

Changed:

- Settings screenshots and docs refreshed for the 0.2.8 layout.
