# Pelmet 0.2.25

Fixed:

- Dragging an app launcher off the menu bar now removes it. Before, macOS
  refused the drag, the icon snapped back, the release counted as a click
  and the app opened. Worse, on macOS 27 that refused drag switches the
  whole app off under System Settings › Menu Bar › Allow in the Menu Bar,
  which took Pelmet's own icon down with it. If your Pelmet icon vanished
  after such a drag, turn Pelmet back on in that list.
