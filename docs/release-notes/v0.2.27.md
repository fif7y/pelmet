# Pelmet 0.2.27

Fixed:

- A Pelmet item placed right after the clock (or any of Apple's own icons
  at the right end of the bar) kept getting dragged toward a slot that
  doesn't exist. Every time the bar collapsed, Pelmet tried again and the
  cursor blinked. Apple's trailing icons don't move, so the closest slot
  is the one the item was already in.
- Now Playing sitting left of the Pelmet icon could pull a visible item
  into the hidden side. Only Apple's icons right of the Pelmet icon count
  as the trailing group now.
- Removed Pelmet items left their slot behind in the saved layout.
  Cleaned up on launch, nothing visible changes.
