# Pelmet 0.2.24

A follow-up to 0.2.23, for the same setup: a notch app like Sconce next to
Pelmet.

Fixed:

- Moving the pointer across the notch revealed the hidden icons. Nothing
  draws under the hardware cutout, so Pelmet read the empty spot as the menu
  bar and treated the pass as a hover. The notch no longer counts as the bar,
  for hover, click or rehide.
