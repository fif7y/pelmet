# Pelmet 0.2.0

**Nook is now Pelmet.** A pelmet is the board above a window that hides the
curtain hardware — this one does it for your menu bar. Same app, same author,
new name (the old one collided with Barnes & Noble's NOOK and other Mac apps).

What happens on update:

- All your settings migrate automatically — sections, icon order, separators,
  reveal behavior, per-display settings. Your old settings stay on disk, so
  downgrading to 0.1.x still works.
- **You'll be asked to re-grant Accessibility (and Screen Recording, if you
  had it enabled).** The app's identity changed, and macOS ties permissions to
  it. One-time.
- Launch at login is re-registered under the new identity. If a stale "Nook"
  entry lingers in System Settings → General → Login Items, it's safe to
  remove.
- If you updated in place (rather than a fresh DMG install), the app file in
  /Applications may still be named Nook.app — rename it to Pelmet.app if you
  like; everything works either way.
- Homebrew users: the cask is now `fif7y/tap/pelmet`.
