# Pelmet 0.2.1

Smooths the Nook → Pelmet update for existing users:

- The app now renames its own bundle from Nook.app to Pelmet.app on first
  launch, before asking for any permission — updating in place no longer
  leaves a mis-named app, and the Accessibility grant attaches cleanly.
- Onboarding now warns updaters about the leftover "Nook" row in System
  Settings → Accessibility: it belongs to the old identity and no longer
  works. Remove it with −, then grant the new Pelmet entry.
- The Accessibility prompt re-fires for migrated installs so the correct
  Pelmet row is always registered.

If you already updated to 0.2.0 and Pelmet isn't hiding anything: remove the
old Nook row from System Settings → Accessibility, grant the Pelmet entry,
and relaunch the app.
