# Pelmet 0.2.5

New:

- Clicking the clock opens Notification Center again, even while icons are
  hidden. macOS refuses that click whenever anything is hidden, so Pelmet
  shows everything for the blink it takes the click to land, then hides
  again. You'll see the hidden icons flash for about half a second. Turn it
  off in Settings › Menu Bar › Notification Center if you prefer the
  two-finger swipe from the right edge of the trackpad, which always works.
