# Pelmet 0.2.32

Added:

- Siri and Time Machine can each go where you want. macOS draws both from
  one process, so Pelmet could only ever hide them as a pair, and the
  editor showed them as a single tile it couldn't move. Turn on Pelmet's
  own Siri and Time Machine in Settings → Menu Bar and each becomes an
  icon like any other: place it, hide it, reveal it. Apple's version
  switches off in System Settings while Pelmet's is on, so you never see
  two, and comes back if you turn Pelmet's off. Time Machine shows the
  latest backup and its disk, backs up now, skips a running backup and
  opens the backup browser (#19, thanks @0kommanix).

Fixed:

- That locked tile was labelled "System" and drew a blank square, which is
  why Time Machine was so hard to find in the editor. It now shows both
  marks with a lock, sits back from the icons you can drag, and says what
  to do about it.
- Pelmet could spend eight seconds at launch waiting for icons that had
  already settled, which delayed the first hide on a fresh login.
