# Pelmet 0.3.2-beta.1

First beta of 0.3.2, on the beta channel only (Settings › About › "Get beta releases").

Fixed:

- A double-click on the chevron now reveals Always Hidden too, like the Menu Bar settings say. It only ever worked in empty menu bar space, and on the chevron the second click shut the bar again (#77, thanks @kaypeter87).
- ⌥-click on the chevron reveals Always Hidden on macOS 27 too. macOS 27 wasn't telling Pelmet the ⌥ key was down, so it acted like a plain click.

Also:

- The double-click setting says where it works: on the chevron, and in empty menu bar space when "Reveal on click in empty menu bar area" is on.
