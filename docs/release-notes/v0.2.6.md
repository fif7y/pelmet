# Pelmet 0.2.6

Fixed:

- Dragging the first icon of the Hidden section into Always Hidden with
  ⌘ held now sticks. It moved in the bar but the editor never followed,
  so the next reveal put it back.
- A ⌘-drag no longer nudges the icons it lands next to into the wrong
  section.
- Double-clicking the empty bar to see everything is smooth. The first
  click of the double used to collapse the bar right before the second
  click reopened it, and the Always Hidden icons slid in uncovered.
  Clicking a revealed bar once still hides it, after a short pause so a
  double-click can be told apart.
