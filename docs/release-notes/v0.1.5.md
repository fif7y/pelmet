# Nook 0.1.5

**Nook is becoming Pelmet.** A pelmet is the board above a window that hides
the curtain hardware — the same job this app does for your menu bar. The name
changes because "Nook" collides with existing products (Barnes & Noble's NOOK
among others).

This release only re-points the update feed to Pelmet's new home. The next
update you receive will install as Pelmet, migrate all your settings
(sections, icon order, separators, per-display behavior), and keep updating
from there. Nothing else changes in this build.
