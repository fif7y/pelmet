# Pelmet 0.2.35

New:

- A Focus item. macOS takes its own Focus icon out of the menu bar the
  moment any icon is hidden, so Pelmet draws one: it shows which Focus is
  on, with that Focus's icon, and a click opens the Focus panel in Control
  Center (click again to close it). Right-click opens Focus Settings. Turn
  it on in Settings › Menu Bar.
- Show when active, or always. Media controls, Time Machine and Focus get
  the same choice System Settings offers for Apple's icons: in the bar
  only while active, or all the time. Focus defaults to always, so at rest
  it is the button that opens the Focus panel.

Fixed:

- Dragging any Pelmet item off the menu bar now turns it off in Settings,
  the way the app launchers already did. Before, the other items could not
  be dragged off: the attempt left them stranded at the left end of the
  bar, and could make macOS stop showing every Pelmet icon until Pelmet
  was allowed again under System Settings › Menu Bar › Allow in the Menu
  Bar.
- A Pelmet item placed to the right of an Apple icon you had hidden (Sound,
  for one) could land one slot to the left of it instead.
