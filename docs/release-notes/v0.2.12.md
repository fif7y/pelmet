# Pelmet 0.2.12

Fixed:

- Menu bar items drawn as a custom view (Little Snitch's traffic monitor,
  DBngin's helper) never showed up in the layout editor and could not be
  hidden. Pelmet now attributes any item to the process that owns it, and
  logs the ones it still cannot read so they can be reported.
- On some Macs the Accessibility request left no Pelmet row in System
  Settings at all, so the permission had to be added by hand with the +
  button. Pelmet now registers first and only clears a stale row on a
  second press.

Docs:

- FAQ entry for a missing Accessibility row and for running Pelmet from
  the disk image instead of Applications.
