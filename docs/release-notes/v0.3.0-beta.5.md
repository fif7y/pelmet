# Pelmet 0.3.0-beta.5

Fifth beta of 0.3.0, on the beta channel only (Settings › About › "Get beta releases", 0.2.41 or later). Everything from beta.4, plus:

New:

- Icon spacing. Settings › Behavior has one slider for the gap between
  menu bar icons, from tightest to widest, with the macOS default in the
  middle. It's macOS's own setting: Apply writes it, restarts the system
  icons and relaunches Pelmet, so the clock, Control Center and Pelmet's
  own items change at once. Other apps follow when they next open (the
  card lists the ones still waiting), or log out and back in for all of
  them. Reset puts the macOS default back.
